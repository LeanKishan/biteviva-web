# BiteViva Web

Next.js 16 / React 19 / TypeScript / Tailwind frontend for the BiteViva AI nutrition platform.

The full source code is in the **[v1.0-source release](https://github.com/LeanKishan/biteviva-web/releases/tag/v1.0-source)** — download the tarball, extract, and commit normally on a clean machine.

## Stack
Next.js 16 - React 19 - TypeScript - Tailwind CSS - static export. Statically hosted on AWS S3 + CloudFront, authenticating via AWS Cognito (OAuth 2.0 / OpenID Connect with PKCE).
